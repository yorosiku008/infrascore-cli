InfraScore JP オンボーディングガイド

AWSインフラ健全性スコアリングCLI — 5分でセットアップ完了

STEP 1

動作環境の確認

InfraScore JP は Python 3.9 以上が必要です。以下のコマンドで確認してください。

python --version
# Python 3.9.x 以上であれば OK
STEP 2

リポジトリのクローンとインストール

git clone https://github.com/yorosiku008/infrascore-cli.git
cd infrascore-cli
pip install -r requirements.txt
rich（ターミナル描画）と boto3（AWS SDK）がインストールされます。
STEP 3

デモモードで動作確認（AWS不要）

AWS認証情報がなくてもデモデータで機能確認できます。

python main.py --demo
スコアバー、グレード、改善項目の一覧が表示されれば成功です。
STEP 4

AWS認証情報の設定

実際のAWS環境をスキャンするには、AWS認証情報が必要です。

aws configure
# または ~/.aws/credentials に直接記載
必要なIAM権限: cloudwatch:DescribeAlarms, cloudwatch:GetMetricStatistics, ec2:DescribeSecurityGroups, ec2:DescribeVolumes, s3:ListBuckets, s3:GetBucketEncryption
STEP 5

実環境のスキャン実行

# デフォルトプロファイル
python main.py

# 特定プロファイルを指定
python main.py --profile my-aws-profile

# Markdownレポートも保存
python main.py --profile my-aws-profile --output-md
